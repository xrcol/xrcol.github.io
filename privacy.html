Privacy Policy

Thank you for using the Markdown Clipper extension. This privacy policy is designed to help you understand how we collect, use, and protect your personal information.

Information Collection

We collect the following types of information:

  • Web content you choose to convert to Markdown format
  • Extension configuration settings
  • Basic usage statistics (such as feature usage frequency)

Information Usage

We use the collected information for:

  • Providing core functionality: converting selected content to Markdown format
  • Saving your preferences
  • Improving extension functionality and user experience

Information Storage

All data is stored locally in your browser, and we do not upload data to any servers

User Rights

As a user, you have the following rights:

  • Access and export all your saved Markdown content
  • Clear all data stored by the extension at any time
  • Choose whether to use optional features like beautification

Policy Updates

We may update this privacy policy from time to time. Any significant changes will be notified to you when the extension updates.

Contact Us
